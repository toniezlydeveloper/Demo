# Demo
The purpose of this project is to showcase the best coding and development practices—clean architecture, modular design, and extendable systems—that I use in my work.

The external systems I used:

FMOD: advanced audio for immersive feedback

NaughtyAttributes: for cleaner, faster editor setup

DOTween: for UI tween handling

The built-in systems I used:

Grid: for seamless level setup

Particle System, Shaders, Post Processing: to make functionality look crisper

As the base of my project, I used my own set of tools: https://github.com/toniezlydeveloper/Internal.git

I also created my own systems especially for this game:

Game Loop: easy to track and modify

Movement System: can be seamlessly extended

Bullet Reflection System: extremely simple but scalable

Parallax Background: just a nice touch

Extremely Simple "AI": bots that shoot bullets at regular intervals

Putting that together, I created a fast-paced game where players strategically dash to reflect bullets and defeat enemies.
